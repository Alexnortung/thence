Reactive derived values for programs built at runtime.

## Usage

Install with your package manager

```bash
$ npm install thence
$ pnpm add thence
$ bun add thence
$ yarn add thence
```

```ts
import { hello } from "thence";

console.log(hello("World")); // Hello, World!
```
